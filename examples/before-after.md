# Synthetic interview synthesis

This is a fictional illustration, not a measured model improvement.

Input: `I1: fewer setup screens please.` / `I2: I prefer a guided setup.`

Before: "Users want a simpler setup because they dislike learning new software."

After: "Fewer setup screens preferred [I1]; guided setup preferred [I2]. Preferences differ.
An explanation for either preference is not established by these excerpts."
